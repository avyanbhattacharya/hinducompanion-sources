# hinducompanion-sources

Curated public-domain and openly-licensed source list for **hinducompanion.com** —
a Hindu religious companion site (panchang, mantras, festivals, katha).

Every entry here was chosen so the site can be built **without copying
copyrighted translations, lyrics, images, or site content**. The operator is
US-based, so all copyright calls use **US law**: works published before
1930 are public domain; otherwise life + 70 years.

## The one rule

> The Sanskrit verses are ancient and free. The danger is never the mantra —
> it is **someone's modern translation, transcription, arrangement, photo,
> or recording** of it.

## Verification checklist (run per item before publishing)

1. Is the *specific edition/translation/recording* pre-1930, or did its author die 70+ years ago?
2. If it's a website's transcription: does that site permit reuse? (See the sanskritdocuments.org trap in `sources/sanskrit.md`.)
3. If it's an image: what does its license tag say — PD, CC-BY, or CC-BY-SA?
4. If it's audio: who owns the *recording*, separate from the lyrics?
5. When in doubt, write your own summary and link out instead of copying.
